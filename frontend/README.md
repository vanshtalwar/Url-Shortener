# Zelqit frontend

Angular 14 + Tailwind CSS 3.4. Use Node 16 (`nvm use`).

```bash
npm install
npx ng serve    # http://localhost:4200 (expects the backend on http://localhost:3000)
npx ng build    # production build → dist/frontend
```

See the [project README](../README.md) for setup, settings, deployment and the API.
